# 🔐 دليل شاشة تسجيل الدخول — Ultimate Edition

دليل سريع للميزات الجديدة والإضافات اللي اتعملت على نظام تسجيل الدخول.

---

## 📦 الملفات الجديدة/المحدثة

| الملف | الوصف |
|-------|-------|
| `login_helpers.py` | ✨ **جديد** — الأصوات + Hijri + QR + Translations |
| `login_advanced.py` | ✨ **جديد** — Stats + EOTM + Badge |
| `login_window.py` | 🔄 **محدث بالكامل** — كل الميزات |
| `settings_tab.py` | 🔄 **محدث** — قسم صورة الخلفية |
| `theme.py` | ⚙️ **مطلوب** — 6 ثيمات (اتعمل قبل كده) |

---

## ✨ الميزات الجديدة

### 🎨 التصميم والشكل

- **6 ثيمات**: Dark Navy, Dark Purple, Light Clean, Nord, Sunset, Forest
- **خلفية gradient** تلقائيًا حسب الثيم
- **صورة خلفية مخصصة** (مع تعتيم 60%)
- **Fade in animation** عند فتح الشاشة
- **Shake animation** عند الخطأ
- **Drag window** — حرّك النافذة من أي مكان

### 👤 المستخدم

- **تحية حسب الوقت** (صباح/نهار/مساء/ليل)
- **رسالة ترحيب شخصية** مع آخر دخول
- **التاريخ الهجري** تلقائيًا
- **معاينة قوة كلمة المرور** أثناء الكتابة
- **إظهار/إخفاء الباسورد**

### 🔒 الأمان

- **حماية Brute Force** — 5 محاولات → قفل 5 دقايق
- **Progress bar** للمحاولات
- **رسائل خطأ مخصصة** (مستخدم مش موجود / باسورد غلط)
- **تحذير "متبقي X محاولات"**
- **Auto-lock** بعد 30 دقيقة خمول

### 🎯 الأدوات السريعة

- **QR Code** للدخول السريع
- **إحصائيات اليوم** (حجوزات، إيرادات، عملاء)
- **موظف الشهر** (أكثر إيرادات)
- **بطاقة الموظف** للطباعة (مع QR)
- **تبديل اللغة** (عربي/إنجليزي)
- **تبديل الثيم** (☀️/🌙)

### 🔊 الأصوات (Windows)

| الحالة | النغمة |
|--------|--------|
| نقرة | 1000 Hz × 25ms |
| نجاح | 700 → 900 → 1200 Hz |
| خطأ | 500 → 300 Hz |
| تحذير | 600 Hz |
| قفل الحساب | 400 → 250 Hz |
| دخول ضيف | 500 → 800 → 1000 Hz |
