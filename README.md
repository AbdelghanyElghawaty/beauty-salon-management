# 💈 Barber Shop Management System

نظام إدارة صالون حلاقة متكامل مبني بـ **Python** و **PySide6** مع دعم كامل للغة العربية وواجهة عصرية.

---

## ✨ الميزات

### 🔐 الأمان والتفعيل
- **نظام ترخيص متكامل** — كل نسخة مربوطة ببصمة الجهاز (Hardware ID)
- **دعم الاشتراكات محددة المدة** — أسبوع، شهر، 3 شهور، سنة، أو دائم
- **حماية ضد التلاعب** — كشف تغيير ساعة النظام، ومنع نسخ الترخيص لأجهزة تانية
- **بصمة متسامحة** — بتتعامل مع تغيير قطعة واحدة في الجهاز (رام/هارد)
- **تشفير PBKDF2** لكلمات المرور مع دعم الترقية التلقائية من SHA256 القديم

### 👥 إدارة المستخدمين والصلاحيات
- **نظام صلاحيات متكامل** — 30+ صلاحية موزعة على 9 مجموعات
- **قوالب جاهزة (Presets)** — مدير، حلاق، كاشير، مسؤول مخزون، HR، محاسب، عارض
- **دورين رئيسيين** — سوبر أدمن (كل الصلاحيات) وموظف (صلاحيات محددة)
- **سجل عمليات (Audit Log)** — تسجيل كل حركة في النظام مع إمكانية الفلترة

### 💈 إدارة الصالون
- **الخدمات والأسعار** — إضافة/تعديل/تعطيل/حذف مع Soft Delete
- **العملاء** — مع نظام نقاط الولاء (VIP بعد 10 نقاط)
- **الحجوزات** — مع دعم خدمات إضافية وطرق دفع متعددة (كاش/فيزا/محفظة)
- **الورديات** — تسجيل الإيرادات حسب طريقة الدفع لكل وردية

### 👥 إدارة الموظفين (اختياري)
- **قائمة الموظفين** — مع بيانات كاملة (تليفون، رقم قومي، وظيفة، إيميل)
- **الحضور والانصراف** — تسجيل يومي مع حساب ساعات العمل
- **السلف والخصومات والمكافآت** — إدارة كاملة للمعاملات المالية
- **حساب الرواتب الشهري** — تلقائي بناءً على الراتب الأساسي + العمولات + المكافآت - السلف - الخصومات
- **تقارير الأداء** — حسب إيرادات كل موظف وعدد حجوزاته

### 📦 إدارة المخزون (اختياري)
- **المنتجات** — مع باركود، كمية، وحدة، حد أدنى، سعر شراء وبيع
- **الوارد والصادر** — تسجيل كل حركة مع المورد والسبب
- **التنبيهات الذكية** — تنبيه للمنتجات اللي قربت تخلص أو قربت تنتهي
- **تقارير المخزون** — قيمة المخزون والربح المتوقع حسب الفئة

### 💼 الإدارة والمالية (اختياري)
- **Dashboard** — ملخص اليوم والشهر والتنبيهات السريعة
- **المصاريف** — إضافة/تصنيف/فلترة حسب التاريخ
- **تقرير الأرباح والخسائر** — مع هامش الربح
- **التحليلات** — المصاريف حسب الفئة

### 📊 التقارير
- **فلترة بالتاريخ** — يوم، أسبوع، شهر، 3 شهور، سنة، أو تاريخ مخصص
- **6 كروت إحصائية** — إيرادات، حجوزات، عملاء، كاش، فيزا، محفظة
- **4 تقارير تفصيلية**:
  - أعلى الخدمات مبيعاً
  - إيرادات الحلاقين
  - أكثر الأيام ازدحاماً
  - العملاء غير النشطين
- **تصدير Excel** لكل التقارير

### 🎨 واجهة المستخدم
- **6 ثيمات** — Dark Navy, Dark Purple, Light Clean, Nord, Sunset, Forest
- **دعم كامل RTL** للعربية
- **واجهة عصرية** — Cards، Soft shadows، تنقل سلس بين التابات
- **إشعارات ذكية** — Toast بدل صناديق الحوار المزعجة
- **اختصارات لوحة المفاتيح** — إضافة، حذف، بحث، تحديث

### 💾 البيانات والنسخ الاحتياطي
- **SQLite** — قاعدة بيانات محلية سريعة بدون سيرفر
- **نسخ احتياطي تلقائي** — عند كل تسجيل خروج وإغلاق للبرنامج
- **استعادة النسخ** — عرض النسخ الموجودة واستعادة أي منها
- **WAL Mode** — أداء أفضل ويمنع "database is locked"
